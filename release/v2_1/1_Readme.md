# Migration Intelligence Platform (v2.1 Multi-SaaS)

## Overview
Enterprise-grade data validation and migration intelligence engine supporting:
- Multi-database (Postgres, MySQL, Oracle, BigQuery, Databricks)
- SaaS multi-tenant execution
- Intelligent profiling, matching, FK inference
- Rule-based validation (C01–C10)

## Key Features
- Adapter-based DB abstraction
- Cross-DB SQL compiler
- Intelligent scoring engine
- DAG-based rule execution
- Explainability engine
