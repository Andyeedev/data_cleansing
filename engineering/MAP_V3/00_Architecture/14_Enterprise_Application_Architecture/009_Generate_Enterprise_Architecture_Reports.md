# Purpose

Generate the complete suite of enterprise architecture reports for the MAP Nexus™ platform.

This module consolidates the outputs from all previous architecture modules into a professional reporting package suitable for architects, developers, project managers, governance teams and executive stakeholders.

This module shall not modify architecture.

This module shall not perform validation.

It generates reports only.
