New Rule Gate (before every implementation)

Instead of letting OpenCode start coding immediately, require:

1) Requirement Understanding
- Explain what it believes the task is.

2) Three Technical Recommendations
- Architecture option A
- Architecture option B
- Architecture option C
- Pros/Cons
- Recommended option

3) Impact Analysis
- Existing components affected
- Existing docs affected
- Existing DB objects affected
- Existing APIs affected

4) Implementation Plan
- Files
- Database
- API
- CLI
- Frontend
- Testing

5) Wait for Approval
- No code until you approve.
