## What Was Accomplished

### 1. Password Hashing (bcrypt)
- Updated `auth_service.py` to query `platform.users` table
- Verifies bcrypt password hash using passlib
- Returns user_id and tenant_id in JWT token
- Created migration script to hash admin password

### 2. RBAC Middleware
- Created `app/api/core/auth/rbac.py` with two dependencies:
  - `require_permissions(*perms)` — checks specific permissions
  - `require_role(*roles)` — checks role membership
- Queries `user_roles`, `roles`, `role_permissions`, `permissions` tables
- Supports role hierarchy and expiration

### 3. Tenant Isolation
- Added `get_current_user_with_tenant()` dependency
- Validates tenant_id exists in JWT token
- Services can use tenant_id for query filtering

## Usage Examples

### Protect a route with permissions:
```python
from app.api.core.auth.rbac import require_permissions

@router.get("/admin")
def admin_route(current_user=Depends(require_permissions("admin:read"))):
    return {"message": "Admin access granted"}
```

### Protect a route with roles:
```python
from app.api.core.auth.rbac import require_role

@router.delete("/{id}")
def delete_item(id: str, current_user=Depends(require_role("admin", "super_admin"))):
    return {"message": "Deleted"}
```

### Get tenant context:
```python
from app.api.core.auth.dependencies import get_current_user_with_tenant

@router.get("/items")
```
