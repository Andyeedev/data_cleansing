# Technical SEO Notes

## URLs
- Use clean, descriptive URLs
- All pages use .html extension
- Internal links use relative paths
- URL structure: `https://migrationassurance.com/[page].html`
- Avoid query parameters for page navigation
- Use hyphens to separate words in URLs

## Performance
- CSS and JS are external (cacheable)
- Images should be WebP format with PNG/JPEG fallbacks
- Lazy loading for below-fold images
- Use `loading="lazy"` attribute on images
- Minify CSS and JavaScript assets
- Enable gzip/brotli compression on server
- Leverage browser caching with appropriate cache headers
- Preload critical above-the-fold resources

## Accessibility
- All images have descriptive alt text
- ARIA labels on interactive elements
- Skip navigation link at top of each page
- Focus management for modals and popups
- Colour contrast ratios meet WCAG 2.1 AA standards
- Form inputs have associated labels
- Keyboard navigation support throughout
- Screen reader friendly heading hierarchy (h1-h6)

## Indexing
- robots.txt should allow all pages
- sitemap.xml should include all pages
- No noindex tags on any page
- Submit sitemap to Google Search Console and Bing Webmaster Tools
- Ensure consistent canonical URLs across all pages
- Use hreflang tags if expanding to multiple languages
- Implement structured data validation via Google Rich Results Test

## Meta Tag Implementation
All pages should include the following meta tags in the `<head>` section:

```html
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta http-equiv="X-UA-Compatible" content="IE=edge">
```
