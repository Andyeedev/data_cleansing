# AZ-02 – Azure Landing Zone Design

## Migration Assurance Platform (MAP)

Version 1.0
Status: Complete

---

# Purpose

This document defines the Azure Landing Zone Design for the Migration Assurance Platform (MAP).

The Landing Zone provides the foundational Azure governance, security, resource organisation, and deployment framework upon which all MAP environments will be built.

This design establishes:

* Azure tenant structure
* Management group hierarchy
* Subscription strategy
* Resource organisation model
* Naming conventions
* Tagging standards
* Governance controls
* Azure Policy implementation
* Role-Based Access Control (RBAC)
