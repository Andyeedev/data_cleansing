# MVP-03 – MVP Use Cases

## Migration Assurance Platform (MAP)

Version 1.0
Status: Complete

# Purpose

This document defines the primary business use cases supported by the Migration Assurance Platform (MAP) MVP.

The use cases demonstrate how real users will interact with the platform during enterprise migration and transformation programmes.

The document serves as the foundation for:

* UX Design
* Screen Design
* Workflow Design
* Product Backlog Creation
* User Story Development
* Pilot Customer Validation

# Detailed MVP Use Cases

---

# UC-01 – System Registration

## Objective

Register a system involved in a migration programme.

---

## Primary Actor

Business Analyst

---

## Trigger

A migration programme begins.

---

## Workflow

1. User creates new system record.
2. User enters system details.
3. User assigns ownership.
4. User links applications.
5. System is stored.

---

## Outcome

System becomes available for discovery and governance activities.

---

# UC-05 – Migration Scope Definition

## Objective

Define the systems included within a migration programme.

---

## Primary Actor

Programme Manager

---

## Workflow

1. Select programme.
2. Select systems.
3. Define migration scope.
4. Submit for review.
5. Approve scope.

---

## Outcome

Approved migration scope established.

---
