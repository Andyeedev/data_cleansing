# Phase Overview

Phase 3.5 establishes the complete delivery framework required to build, test, deploy, and operationalise MAP Release 1.

This phase converts the approved business, product, UX, security, Azure, governance, and commercial designs into an executable delivery programme.

The outputs define:

* Delivery strategy
* Agile operating model
* Sprint planning
* Release planning
* Resource planning
* Environment planning
* Test planning
* Deployment planning
* Go-live readiness
* Operational transition
