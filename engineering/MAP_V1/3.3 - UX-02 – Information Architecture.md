# UX-02 – Information Architecture

## Migration Assurance Platform (MAP)

Version 1.0
Status: Complete

---

# Purpose

This document defines the Information Architecture (IA) for the Migration Assurance Platform (MAP).

The Information Architecture establishes how information is organised, structured, navigated, and discovered throughout the platform.

It serves as the foundation for:

* Navigation design
* Screen design
* Dashboard structure
* Search design
* User journeys
* Wireframes
* User interface development

---

# Information Architecture Objectives

The MAP Information Architecture must:

### Make Information Easy to Find

---

### Reduce Navigation Complexity

---

### Support Role-Based Experiences

---

### Improve Operational Efficiency

---

### Support Governance Activities

---

### Enable Future Growth

---

# Architecture Principles

## Programme-Centric

Everything exists within a migration programme context.

---

## Role-Oriented

Information presented according to user role.

---

## Task-Focused

Users reach outcomes quickly.

---

## Consistent

Navigation remains predictable.

---

## Scalable

Future capabilities can be added without redesign.
