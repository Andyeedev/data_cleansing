# BP-07 – Information Blueprint

**Document ID:** BP-07
**Phase:** 2.2 – Blueprint Library
**Owner:** Product Operations / Knowledge Management
**Version:** 1.0

---

# 1. Purpose

The Information Blueprint defines the architecture for all information assets within the Product Operating System.

Its objectives are to:

* Create one source of truth
* Eliminate duplicated documentation
* Improve discoverability
* Standardize document structures
* Ensure governance and version control
* Connect strategic decisions with execution artifacts

The blueprint governs both human-readable documentation and machine-readable metadata.

---

# 2. Information Principles

Information should be:

### Accurate

Reflect the latest approved decisions.

### Accessible

Easy to locate by anyone with appropriate permissions.

### Consistent

Follow standardized templates and naming conventions.

### Traceable

Every artifact should reference its originating decision.

### Governed

Changes require ownership and approval.

### Reusable

Information should be modular rather than duplicated.

# 5. Information Ownership

Each information asset must have:

* Business Owner
* Content Owner
* Approver
* Custodian
* Review Frequency

Example:

| Artifact               | Owner                | Review      |
| ---------------------- | -------------------- | ----------- |
| Product Strategy       | Head of Product      | Quarterly   |
| Roadmap                | Product Manager      | Monthly     |
| Product Canon          | Product Office       | Semi-Annual |
| Architecture Standards | Enterprise Architect | Quarterly   |
| KPI Dashboard          | Operations Manager   | Monthly     |

# 6. Metadata Standard

Every document should contain standardized metadata.

Required fields include:

* Document ID
* Title
* Version
* Status
* Owner
* Approver
* Created Date
* Last Updated
* Review Date
* Classification
* Related Documents
* Keywords

Example

Document ID: BP-07

Version: 1.2

Status: Approved

Classification: Internal

Owner: Product Operations

Review Date: 30 June 2027
