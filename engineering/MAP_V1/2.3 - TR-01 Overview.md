# TR-01 – Template & Reference Library Overview

**Document ID:** TR-01
**Phase:** 2.3 – Template & Reference Library
**Owner:** Product Operations Office
**Version:** 1.0

---

# 1. Purpose

The Template & Reference (TR) Library provides a standardized collection of templates, checklists, forms, canvases, playbooks, worksheets, examples, and reference materials that support consistent execution of the Product Operating System (POS).

It transforms the principles defined in the Product Canon and Blueprint Library into practical artefacts that can be used by teams across the enterprise.

The library enables repeatability, governance, quality assurance, and operational efficiency while reducing the need to recreate common documents.

---

# 2. Objectives

The Template & Reference Library aims to:

* Standardize product management documentation
* Reduce administrative effort
* Improve quality and consistency
* Accelerate onboarding
* Support governance compliance
* Enable knowledge reuse
* Improve auditability
* Promote best practices

---

* Standards
* Enterprise guidance

### Layer 2 — Blueprint Library

Defines:

* Enterprise architecture
* Operating models

* Measurement frameworks

---

### Layer 3 — Template & Reference Library

Provides:

* Ready-to-use templates

* Registers

* Examples

# 5. Library Categories

The library is organized into major functional categories.

| Category              | Purpose                                                |
| --------------------- | ------------------------------------------------------ |
| Strategy Templates    | Product vision, strategy, business cases               |
| Discovery Templates   | Research, interviews, opportunity assessments          |
| Planning Templates    | Roadmaps, releases, capacity planning                  |
| Delivery Templates    | User stories, backlogs, sprint planning                |
| Governance Templates  | Decision records, approvals, gates                     |
| Risk Templates        | Risk logs, issue registers, mitigation plans           |
| Financial Templates   | Budgets, forecasts, investment requests                |
| Operational Templates | Runbooks, service reviews, incident records            |
| Measurement Templates | KPI registers, dashboards, scorecards                  |
| Stakeholder Templates | Communication plans, stakeholder maps                  |
| Portfolio Templates   | Portfolio reviews, prioritization, investment tracking |

---

# 6. Template Structure Standard

Each template should contain:

* Template ID
* Title
* Purpose
* When to Use
* Owner
* Required Inputs
* Instructions
* Sections
* Approval Requirements
* Related Documents
* Version History

---

# 7. Template Lifecycle

Templates follow a controlled lifecycle:

1. Identify Need
2. Draft Template
3. Review
4. Pilot
5. Approve
6. Publish
7. Use
8. Improve
9. Archive (if superseded)

---

# 8. Version Control

Each template should include:

* Version Number
* Author
* Reviewer
* Approver
* Effective Date
* Review Date
* Change Summary

Only approved versions may be used for official governance activities.

# 10. Naming Convention

Every template uses a consistent identifier.

Examples:

* TR-ST-001 Product Vision Template
* TR-ST-002 Product Strategy Template
* TR-DI-001 Customer Interview Guide
* TR-PL-001 Product Roadmap Template
* TR-GV-001 Governance Decision Record
* TR-RK-001 Risk Register
* TR-ME-001 KPI Register
* TR-OP-001 Operational Runbook

Where:

* ST = Strategy
* DI = Discovery
* PL = Planning
* GV = Governance
* RK = Risk
* ME = Measurement
* OP = Operations

---

# 11. Governance

The Product Operations Office is responsible for:

* Maintaining the library
* Reviewing templates
* Managing versions
* Retiring obsolete artefacts
* Ensuring alignment with the Product Canon
* Publishing approved templates

---

# 12. Usage Guidelines

Templates should:

* Be used as the enterprise standard
* Be tailored only where approved
* Retain mandatory governance sections
* Be stored in approved repositories
* Reference related Canon and Blueprint documents
* Be reviewed after significant organizational changes

---

# 13. Success Measures

The Template & Reference Library is successful when:

* Teams consistently use approved templates.
* Documentation quality improves.
* Governance effort is reduced.
* Audit findings decrease.
* Onboarding time is shortened.
* Work products are reusable across the enterprise.
* Continuous improvement is supported through standardized artefacts.
