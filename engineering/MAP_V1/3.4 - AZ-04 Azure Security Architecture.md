## Migration Assurance Platform (MAP)

# Purpose

This document defines the Azure Security Architecture for the Migration Assurance Platform (MAP).

The Azure Security Architecture establishes the cloud security model used to protect:

* Users
* Data
* Applications
* Infrastructure
* APIs
* Operational services

The design aligns with:

* MAP Security Architecture (PD-04)
* Azure Well-Architected Framework
* Microsoft Cloud Adoption Framework
* Zero Trust Principles
* Microsoft Founders Hub guidance
