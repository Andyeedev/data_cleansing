**Phase 2.3 – Template & Reference Library**

**Document ID:** TR-13
**Version:** 1.0
**Status:** Complete

---

# 1. Purpose

The Reference Guides & Playbooks provide practical implementation guidance for organisations adopting the Migration Assurance Platform.

While:

* The **Product Canon** defines what MAP is,
* The **Blueprint Library** defines how MAP is structured,
* The **Template Library** provides artefacts,
* The **SOP Library** defines operational processes,

the Playbook Library explains:

> How experienced practitioners successfully execute Migration Assurance projects in real-world environments.

---

# 2. Playbook Framework

## Structure

Each playbook contains:

| Section         | Purpose              |
| --------------- | -------------------- |
| Objective       | Why it exists        |
| When to Use     | Applicability        |
| Inputs          | Required information |
| Activities      | Recommended actions  |
| Deliverables    | Expected outputs     |
| Risks           | Common pitfalls      |
| Success Factors | Best practices       |

---

# 3. PB-01 – Migration Assessment Playbook

## Purpose

Guide teams through migration readiness assessment.

---

### When Used

Before any migration programme begins.

---

### Activities

1. Identify source systems.
2. Identify target systems.
3. Assess business criticality.
4. Assess technical complexity.
5. Identify migration constraints.
6. Assess governance requirements.

---

### Deliverables

* Assessment Report
* Migration Readiness Score
* Risk Register

---

### Common Risks

* Incomplete system inventory
* Missing SMEs
* Unknown dependencies

---
