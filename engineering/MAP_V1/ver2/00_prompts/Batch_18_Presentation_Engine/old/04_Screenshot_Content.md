# Module 04 — Screenshot Content

**Purpose:** Generate screenshot metadata for dashboard views
**Input:** dashboard_preview/ views
**Output:** 04_Screenshot_Content/

---

## Screenshot Specifications

| View | File | Dimensions | Key Elements |
|------|------|------------|--------------|
| Home | dashboard_home.png | 1440x900 | Logo, KPIs, tiles |
| Executive | dashboard_executive.png | 1440x900 | KPI cards, charts |
| Validation | dashboard_validation.png | 1440x900 | Control table, donut |
| Quality | dashboard_quality.png | 1440x900 | Radar, trend line |
| Risk | dashboard_risk.png | 1440x900 | Risk matrix, NO-GO |
| Progress | dashboard_progress.png | 1440x900 | Progress bars |
| Governance | dashboard_governance.png | 1440x900 | Findings table |

---

## Capture Process

1. Open index.html in Chrome/Edge
2. Press F11 for full-screen
3. Navigate to each view
4. Wait for charts to render
5. Capture at 1440x900
6. Save as PNG
