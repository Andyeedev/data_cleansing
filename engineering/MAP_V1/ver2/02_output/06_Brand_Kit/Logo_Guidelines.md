---

## 3. Clear Space

Clear space = 1.5 × validation node diameter

| Logo Version | Node Size | Clear Space |
|--------------|-----------|-------------|
| Primary | 14px radius | 42px all sides |
| Icon | 16px radius | 48px all sides |
| Compact | 9px radius | 27px all sides |

---

## 4. Background Rules

| Background | Logo Version | Notes |
|------------|--------------|-------|
| White (#FFFFFF) | Primary | Primary usage |
| Light (#F8FAFC) | Primary | Acceptable |
| Dark (#111827) | Dark | Required |
| Black (#000000) | Inverted | Required |
| Photography | Primary | Dark overlay required |
| Gradient | App icon | Container only |

---

## 5. Incorrect Usage

**Do NOT:**
- Stretch or distort the logo
- Change the colours
- Add effects (shadows, glows, 3D)
- Place on busy backgrounds without overlay
- Rotate the logo
- Rearrange icon and wordmark positions
- Use low-resolution raster versions
- Remove the validation node
- Change typography weights
- Add text or slogans to the logo

---

## 7. Print Usage

- Use monochrome or single-colour versions
- Minimum 300 DPI for raster exports
- Vector preferred for all print

---

## 8. Partner Usage

Partners may use the MAP logo with prior approval.

Requirements:
- Maintain clear space
- Do not alter colours
- Include trademark symbol ™
