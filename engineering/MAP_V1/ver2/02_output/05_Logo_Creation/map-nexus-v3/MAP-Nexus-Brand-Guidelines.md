The symbol should become instantly recognisable even when the word "MAP" is removed.

---

## 2. Core Symbol

### Concept
Three structured pathways converging into one validated point.

### Representation
"Multiple migration inputs becoming one trusted outcome."

### Hidden Letterforms
The viewer should naturally perceive:
- **M** — from the converging pathway peaks
- **A** — from the central pathway and node
- **P** — from the overall structure

**Note:** Do NOT force the letterforms. Avoid cleverness over clarity.

## 4. Typography

### Primary Font
**Inter** (or Segoe UI Variable, Geist, Manrope, IBM Plex Sans)

### Logo Typography
| Element | Weight | Size | Letter-spacing | Colour |
|---------|--------|------|----------------|--------|
| "MAP" | 700 (Bold) | 36px | 1.5px | #1F2937 |
| "NEXUS" | 300 (Light) | 36px | 1.5px | #6B7280 |
| Subtitle | 400 (Regular) | 11px | 2.5px | #9CA3AF |

### Typography Rules
- "MAP" is the dominant visual element
- "NEXUS" remains readable but secondary
- Subtitle is understated
- Typography should feel like part of the logo, not text sitting beside it

## 6. Clear Space

### Minimum Padding
Use the **validation node diameter** as the unit.

```
Clear Space = 1.5 × Node Diameter
```

| Logo Version | Node Size | Clear Space |
|--------------|-----------|-------------|
| Primary (360×100) | 14px radius | 42px all sides |
| Icon (120×120) | 16px radius | 48px all sides |
| Compact (200×60) | 9px radius | 27px all sides |

### Adaptation Rules
- Below 32px: Use favicon only
- 32px–64px: Use icon only
- 64px–128px: Icon or compact
- 128px+: Full primary or vertical

---

## 9. Improper Usage

**Do NOT:**
- Stretch or distort the logo
- Change the colours
- Add effects (shadows, glows, 3D)
- Place on busy backgrounds without overlay
- Rotate the logo
- Rearrange icon and wordmark positions
- Use low-resolution raster versions
- Remove the validation node
- Change typography weights
