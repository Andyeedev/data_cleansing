Overview

This media guide provides instructions for using MAP Nexus™ marketing assets. All assets are HTML templates that can be screenshotted at the specified resolution for use in marketing materials.

Rendering Instructions

  1. Open the HTML template in a modern web browser (Edge, Chrome, Firefox)
  2. Set the browser window to the template's specified dimensions
  3. Take a screenshot using browser dev tools or OS screenshot tools
  4. Save as PNG, JPG, or WebP as needed
