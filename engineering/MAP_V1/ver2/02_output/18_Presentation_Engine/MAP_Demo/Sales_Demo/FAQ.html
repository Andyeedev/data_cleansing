Frequently Asked Questions

20 Common Customer Questions

1. How does MAP Nexus differ from migration tools?

Migration tools move data from source to target. MAP Nexus validates that the migration succeeded. MAP is complementary to migration tools, not competitive. Every migration tool deployment creates a natural opportunity for MAP.

2. Why is MAP built on Azure?

Azure provides enterprise-grade security, compliance, and scale. Microsoft Entra ID, Azure SQL, Azure Monitor, and Azure Storage give MAP the foundation to serve regulated industries with confidence.

3. Can MAP support other cloud platforms?

MAP is Azure-native today. Future roadmap includes multi-cloud support, starting with AWS and Google Cloud. The validation and governance framework is cloud-agnostic by design.

4. Can MAP integrate with our existing tooling?

MAP is designed to integrate with existing migration tools, data platforms, and governance frameworks. REST APIs and Azure-native connectors enable seamless integration.

5. How long does deployment take?

Cloud deployment: 1-2 weeks. On-premises: 4-6 weeks. MAP can be deployed incrementally, starting with a single migration project and expanding.

6. How secure is MAP Nexus?

MAP leverages Azure-native security: Microsoft Entra ID, Azure SQL encryption, Azure Monitor, and enterprise compliance certifications. Security is built-in, not bolted on.

7. How does MAP help with regulatory compliance?

MAP generates audit-ready reports, governance evidence, and compliance documentation automatically. Every validation outcome is tracked and auditable.

8. What industries benefit most from MAP?

Financial Services, Banking, Insurance, Government, Healthcare, Utilities, Housing, and Telecommunications. Any regulated industry where migration failure creates business risk.

9. What is the pricing model?

SaaS subscription with tiered pricing based on migration volume and features. Professional services for implementation. Azure Marketplace for enterprise procurement.

10. Can MAP validate any type of migration?

MAP validates database migrations, data warehouse migrations, application data migrations, and cloud migrations. The validation framework is adaptable to any migration type.

11. What does the executive dashboard show?

Migration readiness, validation status, risk posture, governance compliance, and business outcomes. Executive-friendly language with no technical jargon.

12. How does MAP handle data quality issues?

MAP profiles data quality across completeness, accuracy, consistency, and timeliness. Issues are highlighted with business impact and remediation guidance.

13. Can MAP generate compliance reports?

MAP generates eight executive-ready HTML reports: Executive Summary, Migration Summary, Validation Summary, Governance Summary, Risk Summary, Data Quality Summary, Readiness Report, and Issue Register.

14. Is MAP suitable for large enterprises?

MAP is designed for enterprise scale. Azure-native architecture supports multiple migration projects, concurrent users, and enterprise-wide governance.

15. What support is available?

Enterprise support with SLA, dedicated customer success manager, implementation services, and training. Microsoft Founders Hub backing provides additional support channels.

16. Can MAP be used for ongoing data governance?

MAP validates migrations today. Future roadmap includes ongoing data governance, monitoring, and quality assurance capabilities.

17. How does MAP handle large data volumes?

MAP leverages Azure-native scalability. Validation runs in parallel across multiple workers. Performance is linear with data volume.

18. What training is required?

MAP is designed for business users. Executive dashboards require no training. Implementation and configuration require 1-2 days of training.

19. Can MAP validate cross-system migrations?

MAP validates any source-to-target migration, including cross-system, cross-database, and cross-cloud migrations.

20. What is the product roadmap?

Q1: Foundation and Validation. Q2: Enterprise Scale and Reporting. Q3: Intelligence and Automation with AI. Q4: Platform and Ecosystem with Marketplace.
