# MAP Nexus - Call-to-Action Library

## CTA Variants

### 1. Book a Demonstration
- **Primary CTA**
- **Use case:** Main conversion action
- **Placement:** Homepage, feature pages, landing pages
- **Style:** Primary button (blue)

### 2. Request Early Access
- **Use case:** Pilot programme, new features
- **Placement:** Landing pages, product announcements
- **Style:** Secondary button

### 3. Contact Sales
- **Use case:** Enterprise inquiries, pricing
- **Placement:** Pricing pages, enterprise pages
- **Style:** Primary button

### 4. Join Pilot Programme
- **Use case:** Pilot recruitment
- **Placement:** Pilot landing page, partner pages
- **Style:** Primary button

### 5. Speak with an Expert
- **Use case:** Technical inquiries, consultations
- **Placement:** Technology pages, feature pages
- **Style:** Secondary button

### 6. Download Brochure
- **Use case:** Content downloads
- **Placement:** Homepage, resource pages
- **Style:** Secondary button

### 7. Become a Design Partner
- **Use case:** Partner recruitment
- **Placement:** Partner pages, industry pages
- **Style:** Secondary button

## CTA Usage Guidelines

### Primary CTAs
- Use for main conversion actions
- Maximum one primary CTA per section
- Blue colour (#0078D4)

### Secondary CTAs
- Use for supporting actions
- Multiple secondary CTAs allowed
- Outline or grey style

### CTA Placement
- Above the fold on landing pages
- After key content sections
- In navigation and footer
- Never more than 2 CTAs in visible area

### CTA Language
- Action-oriented verbs
- Clear value proposition
- Urgency when appropriate
- Avoid generic language
