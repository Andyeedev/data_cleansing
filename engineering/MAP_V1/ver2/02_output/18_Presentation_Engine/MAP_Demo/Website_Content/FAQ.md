# MAP Nexus - Frequently Asked Questions

## General (5)

### 1. What is MAP Nexus?
MAP Nexus is an enterprise migration governance and validation platform. It validates that your data migrations are accurate, complete, and compliant.

### 2. What does MAP Nexus do?
MAP Nexus validates data migrations across row counts, balances, relationships, and business rules. It provides executive dashboards, governance frameworks, and compliance reporting.

### 3. Who is MAP Nexus for?
MAP Nexus is for enterprise organisations navigating complex data migrations. It is particularly valuable for regulated industries including financial services, government, healthcare, insurance, and utilities.

### 4. How is MAP Nexus different from migration tools?
Migration tools move data. MAP Nexus validates that data arrived correctly. MAP is complementary to migration tools, not competitive.

### 5. What is the pricing model?
MAP Nexus uses a SaaS subscription model with tiered pricing based on migration volume and features. Contact us for pricing details.

## Security (4)

### 6. How secure is MAP Nexus?
MAP Nexus leverages Azure-native security including Microsoft Entra ID, Azure SQL encryption, and enterprise compliance certifications. Security is built-in, not bolted on.

### 7. Is MAP Nexus compliant with GDPR?
Yes. MAP Nexus supports GDPR compliance with data protection controls, audit trails, and documentation.

### 8. Does MAP Nexus store customer data?
MAP Nexus stores migration metadata and validation results. Customer source data remains in the customer's environment.

### 9. What security certifications does MAP Nexus have?
MAP Nexus is built on Azure, which maintains SOC 2 Type II, ISO 27001, and other enterprise certifications. MAP Nexus inherits Azure's security posture.

### 22. What types of migrations can MAP validate?
MAP Nexus validates database migrations, data warehouse migrations, application data migrations, and cloud migrations.
