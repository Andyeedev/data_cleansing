Overview

MAP Nexus™ (Migration Assurance Platform) is an enterprise demonstration package showcasing the platform's capabilities for data migration validation, governance, and risk assessment.

This package operates completely offline with no installation, no database, and no internet connection required. It can be distributed simply by copying the folder.

Launching the Demo

  1. Open Launch_MAP.html in any modern web browser
  2. Click "Launch Dashboard" to enter the demonstration
  3. Navigate using the tiles or sidebar menu

The demo loads directly into the product home screen — never into raw dashboards.

Navigation

The demonstration provides enterprise-style navigation similar to Microsoft Azure Portal:

DashboardDescription
Executive DashboardHigh-level migration status, KPIs, and executive recommendation
Migration OverviewSource and target platform configuration and entity mapping
Validation CentreControl execution results and validation distribution
Governance CentreFindings, severity distribution, and ownership tracking
Data QualityQuality dimensions, radar analysis, and trend data
Risk AssessmentRisk register, severity matrix, and go/no-go decision
Migration ProgressPhase completion and execution timeline
Executive ReportsSummary reports for executive review and governance

Offline Support

This demonstration operates entirely via file:// protocol. No server, web server, or internet connection is required.

  • Chart.js is bundled locally (no CDN)
  • All fonts use system font stack (Segoe UI)
  • All assets are self-contained
  • No external dependencies

Supported Browsers

  • Microsoft Edge (latest)
  • Google Chrome (latest)
  • Mozilla Firefox (latest)
  • Apple Safari (latest)
