## 4. Pricing Philosophy

### 4.1 Core Principles

| Principle | Description | Application |
|---|---|---|
| **Value Alignment** | Price reflects value delivered | ROI-based pricing |
| **Customer Success** | Pricing grows with customer success | Usage-based expansion |
| **Market Positioning** | Price positions MAP in market | Premium but justified |
| **Simplicity** | Easy to understand and buy | Clear tiers, simple terms |
| **Flexibility** | Options for different buyers | Multiple models, terms |

### 4.2 Value Proposition for Pricing

| Stakeholder | Value Delivered | Pricing Justification |

| Head of Migration | Speed, quality, visibility | Efficiency gains |
| Enterprise Architect | Architecture fit, integration | Technical value |
| QA Lead | Quality, compliance | Risk mitigation |
| CFO | Cost savings, predictable spending | TCO comparison |

### 4.3 Pricing Strategy Options

| Strategy | Description | Pros | Cons |
|---|---|---|---|
| **Cost-Plus** | Cost + margin | Simple, predictable | Doesn't capture value |
| **Competitive** | Match/beat competitors | Market-aligned | Price pressure |
| **Value-Based** | Price based on value | Maximises revenue | Complex to implement |
| **Penetration** | Low price for market share | Fast adoption | Lower margins |
| **Skimming** | Premium price, early adopters | Higher margins | Slower adoption |

**MAP Recommended Strategy: Value-Based Pricing** with competitive benchmarking.

## 5. Pricing Model Options

### 5.1 Model Option 1: User-Based Pricing

| Attribute | Detail |
|---|---|
| **Description** | Price per named user or seat |
| **Metric** | Number of users |
| **Pricing** | Per user per month |
| **Target** | Organisations with predictable user counts |

#### 5.1.1 User-Based Pricing Tiers (Illustrative)

| Tier | Users | Monthly Price | Annual Price | Price per User |
|---|---|---|---|---|
| Starter | 5 | £2,500 | £25,000 | £500/user |
| Professional | 25 | £7,500 | £75,000 | £300/user |
| Enterprise | Unlimited | Custom | Custom | Volume discount |

#### 5.1.2 Pros and Cons

| Pros | Cons |
|---|---|
| Simple to understand | Doesn't scale with value |
| Predictable revenue | Users may not reflect usage |
| Easy to forecast | May discourage adoption |
| Common model | Doesn't capture migration volume |

### 5.2 Model Option 2: Usage-Based Pricing

| Attribute | Detail |
|---|---|
| **Description** | Price based on usage (migrations, data volume) |
| **Metric** | Migrations, data volume, or API calls |
| **Pricing** | Per unit with tiers |
| **Target** | Variable usage patterns |

#### 5.2.1 Usage-Based Pricing Tiers (Illustrative)

| Tier | Migrations/Year | Data Volume | Monthly Price | Annual Price |
|---|---|---|---|---|
| Starter | 5 | 1 TB | £3,500 | £35,000 |
| Professional | 20 | 10 TB | £8,500 | £85,000 |
| Enterprise | Unlimited | Unlimited | Custom | Custom |

#### 5.2.2 Pros and Cons

| Pros | Cons |
|---|---|
| Aligns price with value | Unpredictable revenue |
| Scales with customer success | Complex billing |
| Fair pricing | May penalise heavy users |
| Encourages adoption | Revenue forecasting challenges |

### 5.3 Model Option 3: Tiered Pricing

| Attribute | Detail |
|---|---|
| **Description** | Fixed tiers with bundled features |
| **Metric** | Feature set + usage limits |
| **Pricing** | Fixed monthly/annual price per tier |
| **Target** | Predictable budgeting, clear value |

#### 5.3.1 Tiered Pricing Structure (Illustrative)

| Tier | Features | Usage Limits | Monthly Price | Annual Price |
|---|---|---|---|---|
| Starter | Core validation | 5 migrations, 1 TB | £3,500 | £35,000 |
| Professional | Full platform | 20 migrations, 10 TB | £8,500 | £85,000 |
| Enterprise | Unlimited | Unlimited | Custom | Custom |

#### 5.3.2 Pros and Cons

| Pros | Cons |
|---|---|
| Simple to understand | May not fit all needs |
| Predictable pricing | Features may not align |
| Easy to sell | May leave money on table |
| Common in SaaS | Upgrade friction |

### 5.4 Recommended Model: Hybrid Tiered + Usage

| Component | Model | Rationale |
|---|---|---|
| Base Platform | Tiered | Predictable, simple |
| Usage Overage | Usage-based | Scales with value |
| Add-Ons | Modular | Flexibility |
| Enterprise | Custom | Negotiation flexibility |

## 7. Value-Based Pricing Framework

### 7.1 Value Driver Analysis

| Value Driver | Description | Quantifiable Benefit | MAP Contribution |
|---|---|---|---|
| **Migration Speed** | Faster migration delivery | 60% time reduction | Automated validation |
| **Quality Improvement** | Fewer defects, issues | 80% fewer defects | Data validation |
| **Compliance Assurance** | Audit-ready compliance | 100% audit readiness | Compliance reporting |
| **Cost Reduction** | Lower migration costs | 30% cost reduction | Efficiency gains |
| **Risk Mitigation** | Reduced migration risk | 80% risk reduction | Validation assurance |

### 7.2 ROI Model Framework

| Component | Calculation | Example |
|---|---|---|
| **Current Cost** | Manual validation effort | £200,000/year |
| **MAP Cost** | Platform subscription | £85,000/year |
| **Cost Savings** | Current - MAP cost | £115,000/year |
| **Efficiency Gains** | Time savings × rate | £80,000/year |
| **Risk Reduction** | Avoided failures × probability | £50,000/year |
| **Total Value** | Savings + Efficiency + Risk | £245,000/year |
| **ROI** | Total Value / MAP Cost | 288% |

### 7.3 Value-Based Price Setting

| Value Delivered | Customer Benefit | Price Justification |
|---|---|---|
| £245,000/year value | Cost savings, efficiency, risk | £85,000 price = 35% of value |
| 288% ROI | Clear financial return | Payback in 4 months |
| 3x value capture | Customer gets 3x what they pay | Strong value proposition |
