## 1. Purpose

This document defines the Microsoft Ecosystem Strategy for the Migration Assurance Platform (MAP). It establishes the relationship framework with Microsoft across the Microsoft for Startups Founders Hub programme, the ISV programme, Azure Marketplace, and co-sell alignment. The strategy ensures MAP achieves deep technical integration with Azure-native services, maximises commercial benefits through Azure credits and programme incentives, and builds a sustainable long-term relationship with Microsoft that delivers mutual value.

### 1.1 Scope

This strategy covers:

- Microsoft for Startups Founders Hub participation and benefits
- Microsoft ISV programme registration and compliance
- Azure Marketplace listing, co-sell readiness, and transaction management
- Technical integration with Azure services (Entra ID, Azure SQL, Azure AI, Azure Key Vault)
- Joint marketing, case studies, and event participation
- Azure credits utilisation and consumption optimisation
- Certification and compliance requirements for Azure Marketplace

### 1.2 Audience

| Role                          | Purpose                                        |
| ----------------------------- | ---------------------------------------------- |
| MAP Executive Leadership      | Strategic alignment and investment decisions    |
| MAP Engineering               | Technical integration and certification        |
| MAP Business Development      | Partner relationship and co-sell execution     |

| Microsoft Partner Team        | Relationship management and programme guidance |
