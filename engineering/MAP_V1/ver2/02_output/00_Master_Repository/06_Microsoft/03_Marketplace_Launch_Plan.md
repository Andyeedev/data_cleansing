## 1. Purpose

This document defines the Marketplace Launch Plan for the Migration Assurance Platform (MAP). It provides the end-to-end plan for listing MAP on Azure Marketplace and Microsoft AppSource, including listing preparation, technical integration, commercial terms, launch execution, and post-launch optimisation. The plan ensures MAP achieves maximum marketplace visibility, a seamless customer purchasing experience, and sustainable revenue growth through marketplace channels.

### 1.1 Scope

This plan covers:

- Azure Marketplace and AppSource listing strategy and positioning
- Listing content preparation: descriptions, screenshots, videos, and documentation
- Technical requirements: SaaS offer type, fulfilment API, billing integration
- Commercial terms: pricing, revenue share, billing models, and support obligations
- Pre-launch, launch, and post-launch activities and milestones
- Marketplace SEO, visibility optimisation, and promotional strategies
- Customer review management and listing iteration

### 1.2 Audience

| Role                          | Purpose                                        |
| ----------------------------- | ---------------------------------------------- |
| MAP Executive Leadership      | Launch approval and investment decisions        |
| MAP Product                   | Listing content and technical requirements     |
| MAP Engineering               | SaaS offer integration and API development     |

| MAP Marketing                 | Listing content, SEO, and launch marketing      |
| MAP Finance                   | Billing integration and revenue recognition     |
