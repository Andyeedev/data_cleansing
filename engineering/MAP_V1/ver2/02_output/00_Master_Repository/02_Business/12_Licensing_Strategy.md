## 1. Purpose

### 1.1 Document Purpose

This document defines the licensing strategy for the Migration Assurance Platform (MAP). It provides a comprehensive framework for license types, terms, management, compliance, and enforcement. The licensing strategy supports the business model, pricing strategy, and go-to-market objectives.

### 1.2 Scope

This licensing strategy covers:

- Licensing philosophy and principles
- License types and models
- License terms and conditions
- License management and entitlement
- Trial and pilot programmes
- Enterprise licensing
- Channel and partner licensing
- Compliance and enforcement
- License automation and tooling
- Legal framework

### 1.3 Audience

| Audience | Use |
|---|---|
| Executive Leadership | Business model alignment |
| Product Management | Feature gating, packaging |
| Sales Team | License options, terms |
| Legal | Contract terms, compliance |
| Engineering | License enforcement |
| Finance | Revenue recognition |

### 1.4 Definitions

| Term | Definition |
|---|---|
| **License** | Permission to use software under specified terms |
| **Entitlement** | Specific rights granted under a license |
| **Activation** | Process of enabling licensed features |
| **Compliance** | Adherence to license terms |
| **Audit** | Verification of license usage |
| **Seat** | Named user or instance licensed |
| **Instance** | Single deployment of software |
| **Subscription** | Time-limited license with recurring payment |
| **Perpetual** | One-time purchase, ongoing use rights |

## 2. Executive Summary

### 2.1 Licensing Strategy Overview

MAP employs a flexible licensing model designed to:

- Align with customer buying preferences
- Support the SaaS-first business model
- Enable enterprise and channel sales
- Maintain compliance and revenue protection
- Scale with customer growth

### 2.2 Key Licensing Models

| Model | Description | Target Buyer | Revenue Model |
|---|---|---|---|
| **SaaS Subscription** | Cloud-hosted, per-seat | All segments | Recurring revenue |
| **Perpetual License** | On-premise, one-time | Enterprise | One-time + maintenance |

## 3. Licensing Philosophy

### 3.1 Core Principles

| Principle | Description | Application |
|---|---|---|
| **Customer-Centric** | Design for customer needs | Multiple buying options |
| **Value-Aligned** | License reflects value | Usage-based options |
| **Revenue-Optimised** | Maximise lifetime value | Expansion-friendly |
| **Compliance-Ready** | Easy to enforce and verify | Automated tracking |
| **Globally Applicable** | Work across jurisdictions | International terms |

### 3.2 Licensing Strategy Options

| Strategy | Description | Pros | Cons |
|---|---|---|---|
| **Per-Seat** | Price per user | Simple, predictable | May discourage adoption |
| **Per-Instance** | Price per deployment | Predictable | Complex sizing |
| **Usage-Based** | Price per use/migration | Scales with value | Revenue variability |
| **Tiered** | Feature bundles | Simple, predictable | May not fit all needs |
| **Hybrid** | Combination approach | Flexible | Complex management |

**MAP Recommended Strategy: SaaS-first with hybrid licensing**
