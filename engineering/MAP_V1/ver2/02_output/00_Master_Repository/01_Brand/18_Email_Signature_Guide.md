# MAP Email Signature Guide

**Document:** Email Signature Standards
**Version:** 1.0
**Date:** June 2026

---

## 1. Standard Format

```
[Name]
[Title]
[Company]
[Email] | [Phone]
[LinkedIn]
```

---

## 2. Styling

| Element | Style |
|---------|-------|
| Name | 14px, 600 weight, #1F2937 |
| Title | 12px, 400 weight, #6B7280 |
| Company | 12px, 500 weight, #667EEA |
| Contact | 12px, 400 weight, #6B7280 |
| Divider | — (pipe character) |

## 3. Logo

Include MAP Nexus Compact logo at bottom.
