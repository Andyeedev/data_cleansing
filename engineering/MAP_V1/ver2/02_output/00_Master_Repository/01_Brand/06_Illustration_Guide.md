# MAP Illustration Guide

**Document:** Illustration Style Guide
**Version:** 1.0
**Date:** June 2026

---

## 1. Style

Enterprise flat vector, technical and clean.

---

## 2. Themes

| Theme | Description | Use Case |
|-------|-------------|----------|
| Migration | Data movement, pathways | Homepage, features |
| Validation | Checkmarks, verification | Success states, reports |
| Governance | Structure, organisation | Compliance, audit |
| Data Flow | Arrows, connections | Architecture diagrams |
| Infrastructure | Cloud, servers, networks | Technical documentation |

---

## 3. Colour Usage

- Use brand colours only
- Maintain visual hierarchy
- Keep illustrations simple

---

## 4. Avoid

- Cartoons
- Mascots
- Comic styles
- 3D renders
- Photorealistic styles

---

*End of Illustration Guide*
