## Renumbering Rules

When adding new files to the Master Repository:

1. **Determine logical position** — Where does this file fit in the reading flow?
2. **Shift existing files** — Renumber files after the insertion point
3. **Maintain no gaps** — Sequential numbering must be continuous
4. **Update this index** — Add the new file and renumber affected entries
5. **Verify** — Check for duplicates and gaps after renumbering

## Appendix A: Renumbering Analysis

**Date:** July 2026
**Trigger:** Batch 10 — UX/UI Design System publishing

### Problem Identified

Previous batches published files with inconsistent numbering:
- Some files had old numeric prefixes (05_, 07_, 10_, 11_, 13_)
- Some files had no prefixes (clean names)
- Some files had Batch 10 prefixes (14_, 15_, etc.)
- Sub-agents assigned numbers based on highest seen, not logical order

### Resolution Strategy

| Step | Action |
|------|--------|
| 1 | Read all folders to identify current state |
| 2 | Remove ALL existing numeric prefixes |
| 3 | Group files by logical reading flow |
| 4 | Apply sequential numbering (01, 02, 03...) with no gaps |
| 5 | Verify no duplicates, no gaps |
