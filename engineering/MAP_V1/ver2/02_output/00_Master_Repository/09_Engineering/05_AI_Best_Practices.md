# AI Best Practices

**Document:** MAP AI Best Practices
**Version:** 1.0
**Date:** July 2026
**Status:** Official

## Overview

This document outlines best practices for AI-assisted development in MAP.

## Core Principles

1. **AI Assists, Humans Decide** — AI is a tool, not a replacement for judgment
2. **Always Validate** — Review all AI output before using
3. **Security First** — Never compromise security for automation
4. **Document Everything** — Track AI contributions for audit
5. **Continuous Learning** — Improve prompts and processes over time

## Best Practices by Activity

### Code Generation
- Provide clear, specific instructions
- Include context (language, framework, patterns)
- Review for security vulnerabilities
- Test thoroughly

### Test Generation
- Specify test framework and patterns
- Include edge cases and error scenarios
- Verify test assertions are correct
- Maintain test independence

### Documentation
- Verify technical accuracy
- Ensure consistency with code
- Include examples and prerequisites
- Keep documentation current

## Common Pitfalls

| Pitfall | Prevention |
|---------|------------|
| Over-relying on AI | Always review and validate |
| Ignoring security | Run security scans on AI code |
| Poor prompts | Use prompt templates and versioning |
| No documentation | Document AI contributions |
