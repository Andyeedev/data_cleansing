## Document Control

### Purpose

This document defines the comprehensive training programme for the Migration Assurance Platform (MAP) customer pilot deployment. It provides the structured curriculum, delivery methodology, learning paths, and assessment framework required to ensure customers achieve full platform competency across administrator, business user, and executive personas. The programme is designed to accelerate time-to-value and reduce support burden during and after the pilot phase.

### Scope

- Administrator training covering system configuration, user management, and troubleshooting
- Business user training covering daily operations, reports, and workflows
- Executive overview training covering dashboards, KPIs, and strategic value
- Self-paced learning paths including e-learning, video tutorials, and knowledge base
- Hands-on workshops with use-case scenarios and best practices
- Knowledge transfer mechanisms including documentation, recordings, and cheatsheets
- Phased learning roadmaps at 30, 60, and 90 day intervals
- Certification framework for future rollout
- Training materials library (slide decks, labs, quizzes)
- Multi-modal delivery (virtual, on-site, hybrid)

## 1. Training Programme Overview

### 1.1 Programme Mission

The MAP Customer Training Programme ensures every pilot customer achieves platform proficiency within 90 days of deployment kickoff. Training is delivered through a blended model of instructor-led sessions, self-paced e-learning, hands-on workshops, and continuous knowledge transfer activities.

### 1.2 Programme Objectives

| # | Objective                                                | Success Metric                              |
|---|----------------------------------------------------------|---------------------------------------------|
| 1 | Achieve 100% admin certification readiness within 60 days| Admin lab completion rate ≥ 95%             |
| 2 | Achieve 90% business user competency within 45 days     | Quiz pass rate ≥ 85% for all modules        |
| 3 | Reduce support ticket volume by 40% post-training       | Support metrics comparison (pre/post)       |
| 4 | Achieve customer NPS ≥ 8.5 for training experience      | Post-training survey results                |
| 5 | Complete knowledge transfer within pilot window          | All knowledge transfer checkpoints met      |

### 1.3 Training Structure

```
MAP Training Programme
├── Track 1: Administrator Training (24 hours)
│   ├── Module A: System Configuration (8 hrs)
│   ├── Module B: User Management (8 hrs)
│   └── Module C: Troubleshooting (8 hrs)
├── Track 2: Business User Training (16 hours)
│   ├── Module D: Daily Operations (6 hrs)
│   ├── Module E: Reports & Analytics (5 hrs)
│   └── Module F: Workflows (5 hrs)
├── Track 3: Executive Overview (4 hours)
│   ├── Module G: Dashboard & KPIs (2 hrs)
│   └── Module H: Strategic Value (2 hrs)
├── Self-Paced E-Learning (asynchronous)
├── Hands-On Workshops (scheduled)
└── Knowledge Transfer (ongoing)
```

**Learning Objectives:**

- Configure migration rule engine parameters for pilot requirements
- Set up data source connections with proper security settings

**Lab Exercise A1: Initial System Setup**
1. Access the training instance and verify connectivity
2. Configure the platform database connection pool settings
3. Set up three data source connections (source, target, reference)
4. Configure migration rule engine with custom validation rules
5. Set up the validation framework with pass/fail thresholds
6. Verify configuration through the system health dashboard
