## Rules

1. **Preserve all previous versions** — never overwrite `v1.0` when creating `v1.1`
2. **Append new applications** — add new rows to the register without modifying existing entries
3. **Version numbering** — use `v1.0`, `v1.1`, `v2.0` etc.
4. **Status values** — Draft, Ready, Submitted, Accepted, Rejected, Withdrawn
5. **Archive completed applications** — keep all versions for audit trail
