## 1. Overview

This document defines the skill progression framework for engineers working with AI-assisted development on the MAP platform. The roadmap provides a structured path from foundational AI literacy to enterprise AI architecture leadership.

---

## 2. Level 1: Beginner

### 2.1 Skills

- Understanding AI capabilities and limitations in software development
- Basic prompt writing for code generation and explanation
- Using AI for code completion and suggestion
- Reviewing AI-generated code for correctness and quality
- Identifying when AI assistance is appropriate vs. manual authoring
- Understanding AI context window limitations and workarounds

### 2.2 Tools

- GitHub Copilot / Cursor for code completion
- ChatGPT / Claude for code explanation and generation
- AI-powered IDE plugins for inline suggestions
- Basic prompt templates for common patterns

### 2.3 Responsibilities

- Complete AI onboarding training module
- Use AI tools for at least 20% of daily coding tasks
- Participate in AI skill-sharing sessions
- Document effective prompts in team library

### 2.4 Certification Criteria

- Pass AI fundamentals assessment (80% minimum)
- Demonstrate 5 effective AI prompts in code review
- Complete 3 AI-assisted coding exercises
- Submit 2 prompts to team prompt library

### 2.5 Time to Achieve

1–2 months with dedicated learning time

---

## 3. Level 2: Intermediate

### 3.1 Skills

- Advanced prompt engineering with context management
- Using AI for test generation and edge case identification
- AI-assisted debugging and root cause analysis
- Creating custom prompts for MAP-specific patterns
- Evaluating AI output quality and identifying hallucinations
- Combining multiple AI tools for complex workflows
- Understanding prompt injection risks and mitigation

### 3.2 Tools

- Advanced GitHub Copilot features (chat, inline edit)
- AI code review tools
- Custom prompt templates with MAP context
- AI testing frameworks
- Codebase-aware AI assistants

### 3.3 Responsibilities

- Create and maintain 5+ custom prompts for MAP patterns
- Review AI-generated code in pull requests
- Mentor Level 1 engineers on AI tool usage
- Contribute to team prompt library with quality examples
- Identify and report AI tool limitations encountered in practice

### 3.4 Certification Criteria

- Pass advanced prompt engineering assessment
- Create 3 MAP-specific prompt templates accepted into library
- Successfully use AI to identify and fix 5 production issues
- Complete AI code review training module
- Mentor at least 1 Level 1 engineer

### 3.5 Time to Achieve

3–6 months of active AI-assisted development
