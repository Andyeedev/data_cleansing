# How to Capture Dashboard Screenshots

**Purpose:** Manual screenshot capture for Microsoft Founders Hub, investor presentations, website, and marketing materials.

---

## Recommended Browser Settings

| Setting | Value |
|---------|-------|
| Browser | Microsoft Edge or Google Chrome |
| Zoom | 100% |
| Window size | 1440 x 900 pixels |
| Full-screen mode | Press F11 for clean capture |

---

## Screenshot Capture Steps

### 1. Dashboard Home (dashboard_home.png)
1. Open `index.html`
2. Press **F11** for full-screen mode
3. Capture the full screen
4. Save as `screenshots/dashboard_home.png`

### 2. Executive Dashboard (dashboard_executive.png)
1. Click **Executive Dashboard** in the sidebar
2. Wait for charts to render
3. Press **F11** for full-screen mode
4. Capture and save as `screenshots/dashboard_executive.png`

## Tips for Clean Screenshots

1. Close other tabs
2. Hide bookmarks bar (Ctrl+Shift+B)
3. Use F11 for full-screen mode
4. Wait for animations to complete
5. Use 1440x900 for consistent sizing
6. Use PNG format for crisp text
