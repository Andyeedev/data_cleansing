## Capture Instructions

1. Open `dashboard_preview/index.html` in Chrome or Edge
2. Press F11 for full-screen mode
3. Navigate to each view
4. Wait for charts to render
5. Capture at 1440x900
6. Save as PNG in `screenshots/` folder
