MAP Nexus™

Overview

MAP Nexus™ is an enterprise-grade Migration Assurance Platform that validates data migrations before they happen. This package contains a fully self-contained demonstration that operates entirely offline.

How to Launch

Step 1: Open this folder in Windows Explorer

Step 2: Double-click Launch_MAP_Demo.html

Step 3: Click "Launch Dashboard" to begin

Step 4: Navigate using the sidebar menu
