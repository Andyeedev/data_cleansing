# How to Capture Dashboard Screenshots

**Purpose:** Manual screenshot capture for Microsoft Founders Hub, investor presentations, website, and marketing materials.

**Approach:** Manual capture using Microsoft Edge or Google Chrome (approved method until MAP web portal is available).

---

## Prerequisites

1. Open `index.html` in Microsoft Edge or Google Chrome
2. Wait for all charts to render (2-3 seconds)
3. Use browser zoom at **100%** for standard screenshots

---

## Recommended Browser Settings

| Setting | Value |
|---------|-------|
| Browser | Microsoft Edge or Google Chrome |
| Zoom | 100% |
| Window size | 1440 x 900 pixels |
| Full-screen mode | Press F11 for clean capture |

## Tips for Clean Screenshots

1. **Close other tabs** — reduces visual clutter
2. **Hide bookmarks bar** — Ctrl+Shift+B in Chrome/Edge
3. **Use F11** — full-screen mode removes browser chrome
4. **Wait for animations** — let charts fully render before capturing
5. **Consistent sizing** — use 1440x900 for all screenshots
6. **PNG format** — use PNG for crisp text and charts

---

## Usage Rights

Screenshots are suitable for:
- Microsoft Founders Hub application
- Investor presentations
- Website and marketing collateral
- Product demonstrations
- Social media posts

**Do not include:**
- Browser URL bar
- Developer tools
- Debug information
- Technical implementation details
