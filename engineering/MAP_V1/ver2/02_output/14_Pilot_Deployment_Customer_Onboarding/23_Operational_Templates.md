## 1. Purpose

This document defines the standardised operational templates used throughout the MAP (Migration Assurance Platform) Pilot Deployment and Customer Onboarding programme. These templates ensure consistency, quality, and efficiency across all customer engagements by providing pre-built structures for common documents and communications.

The templates serve to:

- Standardise documentation across all pilot deployments
- Reduce time spent creating documents from scratch
- Ensure completeness and consistency of information
- Enable new team members to produce quality documents quickly
- Provide a framework for continuous improvement of processes
- Support audit and compliance requirements through standardisation

---

## 2. Scope

This document applies to all operational templates used by the MAP Customer Success, Engineering, Operations, and Support teams during pilot deployment and customer onboarding.

The templates cover the following activities:

- Pilot kick-off and initiation
- Deployment planning and execution
- Training programme delivery
- Status reporting and communication
- Support ticket management
- Customer health monitoring
- Project closure and handoff

## 4. Template Standards

### 4.1 Format Requirements

| Element | Requirement |
|---------|-------------|
| File format | Markdown (.md) with PDF export capability |
| Page size | A4 equivalent |
| Margins | 1 inch / 2.54 cm |
| Font | System default (rendered as sans-serif) |
| Heading levels | Maximum 4 levels deep |
| Tables | Markdown tables with header rows |
| Lists | Numbered for sequential steps, bulleted for non-sequential |
| Code blocks | Fenced with language specification |
| Images | PNG or SVG with alt text |

### 4.2 Version Control

| Element | Convention |
|---------|-----------|
| Version numbering | Semantic versioning (Major.Minor) |
| Version location | Document header table |
| Change log | Revision history table |
| Review cycle | Quarterly minimum |
| Approval required | Document owner + 1 reviewer |

### 4.3 Usage Guidelines

| Guideline | Description |
|-----------|-------------|
| Complete all fields | Fill in every applicable field; mark N/A for non-applicable |
| Customise for context | Adapt templates to specific customer and engagement type |
| Maintain branding | Follow brand guidelines for visual elements |
| Review before sharing | Always review completed templates before distribution |
| Archive completed documents | Store completed documents in the appropriate repository location |

### 4.4 Template Maintenance

| Activity | Frequency | Responsible |
|----------|-----------|------------|
| Template review | Quarterly | Template owner |
| Feedback collection | Ongoing | All users |
| Update implementation | As needed | Template owner |
| Deprecation review | Annually | Template owner |
| Version update | Per change | Template owner |
