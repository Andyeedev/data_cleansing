Security Architecture

Four foundational principles that underpin the security architecture of the MAP platform

Zero Trust Architecture

Every request is authenticated and authorised regardless of origin. No implicit trust is granted based on network location or previous authentication. All traffic is verified continuously.

Defence in Depth

Multiple overlapping security layers ensure that the compromise of any single control does not result in a breach. Network, application, and data layers are independently secured.

Least Privilege Access

Users and services are granted only the minimum permissions necessary to perform their function. Access rights are regularly reviewed and automatically revoked when no longer needed.

Continuous Monitoring

Real-time monitoring of all platform activity with automated threat detection, anomaly identification, and immediate alerting on suspicious behaviour patterns.

Zero Trust Security Model

MAP implements a comprehensive zero trust security model that assumes no implicit trust for any user, device, or network. Every access request is verified before granting permissions.

  • Verify Explicitly - Always authenticate and authorise based on all available data points including user identity, location, device health, and service workload.
  • Use Least Privilege Access - Limit access with just-in-time and just-enough-access (JIT/JEA), adaptive risk-based policies, and data protection to secure both data and productivity.
  • Assume Breach - Minimise the blast radius and segment access. Verify end-to-end encryption. Use analytics to detect threats and improve defences.
  • Micro-Segmentation - Network segmentation limits lateral movement and enforces access policies at the application and data layer.

Encryption

Industry-standard encryption protecting your data at every stage

AES-256 at Rest

All data stored in the MAP platform is encrypted using AES-256, the gold standard for data-at-rest encryption. Database fields, file storage, and backups are all encrypted.

TLS 1.3 in Transit

All data in transit is protected with TLS 1.3, the latest and most secure transport layer protocol. Perfect forward secrecy ensures past sessions cannot be decrypted.

Azure Key Vault

Encryption keys are managed through Azure Key Vault with Hardware Security Modules (HSMs). Keys are rotated automatically and never exposed to application code.
