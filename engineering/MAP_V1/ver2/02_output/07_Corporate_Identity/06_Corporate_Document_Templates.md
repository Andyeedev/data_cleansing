# 06 — Corporate Document Templates

**Document:** Document Template Standards
**Version:** 1.0
**Date:** June 2026
**Status:** Official

---

## 1. Business Card

| Element | Specification |
|---------|---------------|
| Size | 85mm × 55mm |
| Front | Logo, Name, Title, Email, Phone |
| Back | Logo, Tagline, Website |
| Paper | 350gsm matte |
| Finish | Soft touch lamination |

---

## 2. Letterhead

| Element | Specification |
|---------|---------------|
| Size | A4 (210mm × 297mm) |
| Header | Logo top-left, 20mm margin |
| Footer | Address, contact, website |
| Margins | 25mm all sides |

---

## 3. Proposal

| Element | Specification |
|---------|---------------|
| Cover | Logo, client name, date, title |
| Sections | Executive Summary, Solution, Pricing, Timeline |
| Footer | Confidential, page numbers |
| Font | Inter, 11pt body |

---

## 4. Invoice

| Element | Specification |
|---------|---------------|
| Header | Company name, address, logo |
| Fields | Invoice number, date, due date, items, total |
| Payment | Bank details, payment terms |
| Footer | VAT number, company registration |

---

## 5. Statement of Work

| Element | Specification |
|---------|---------------|
| Sections | Scope, Deliverables, Timeline, Terms |
| Format | Professional, legal language |
| Signatures | Both parties |

## 6. PowerPoint

| Element | Specification |
|---------|---------------|
