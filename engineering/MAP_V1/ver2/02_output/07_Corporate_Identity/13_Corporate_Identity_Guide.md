# 13 — Corporate Identity Guide

**Document:** Master Identity Guide
**Version:** 1.0
**Date:** June 2026
**Status:** Official

---

## 1. Overview

This guide explains how to use every MAP corporate identity asset. It ensures brand consistency across all company-facing communications.

---

## 2. Brand Consistency

### Hierarchy of Authority

| Priority | Source |
|----------|--------|
| 1 | Brand Kit v1.0 |
| 2 | Simplified Website |
| 3 | MAP Nexus V3 Logo System |
| 4 | Master Repository |
| 5 | Detailed Website |

When conflicts arise, defer to the highest authority.

---

## 3. Do's

| Do | Context |
|----|---------|
| Use MAP Nexus™ logos from official sources | All contexts |
| Maintain clear space around logos | All contexts |
| Use brand colours only | All contexts |
| Use Inter font family | All contexts |
| Use approved messaging | All contexts |
| Maintain professional tone | All contexts |
| Use legal name in formal documents | Legal, contracts |
| Use brand name in marketing | Marketing, social |

---

## 4. Don'ts

| Don't | Context |
|-------|---------|
| Alter logo colours or proportions | All contexts |
| Add effects to logos | All contexts |
| Use non-approved fonts | All contexts |
| Use hype language | All contexts |
| Mix brand colours with other palettes | All contexts |
| Use casual tone in formal documents | Legal, contracts |
| Create unapproved logo variations | All contexts |

---

## 5. Naming Rules

---

## 6. Logo Rules

| Rule | Detail |
|------|--------|
| Minimum size | 140px width (primary) |
| Clear space | 1.5× node diameter |
| Approved backgrounds | White, dark, photography with overlay |
| Prohibited | Busy backgrounds, colour alterations |

---

## 7. Messaging Rules

| Rule | Detail |
|------|--------|
| First mention | Full name with trademark |
| Subsequent | MAP |
| Tagline | "Every migration validated. Every outcome assured." |
| Avoid | Hype, superlatives without evidence |
