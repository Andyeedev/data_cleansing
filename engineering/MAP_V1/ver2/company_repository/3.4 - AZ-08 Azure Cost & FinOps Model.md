# AZ-08 – Azure Cost & FinOps Model

## Migration Assurance Platform (MAP)

Version 1.0
Status: Complete

---

# Purpose

This document defines the Azure Cost & FinOps Model for the Migration Assurance Platform (MAP).

The model establishes how Azure costs will be governed, monitored, allocated, optimised, forecasted, and reported throughout the MAP lifecycle.

The model is specifically designed to:

* Maximise Microsoft Founders Hub benefits
* Minimise cloud waste
* Support MVP delivery
* Enable sustainable scale
* Establish financial governance

This document aligns with:

* CG-08 Financial Model & Funding Strategy
* FH-04 Azure Credit Utilisation Plan
* AZ-01 Azure Architecture Strategy
* AZ-02 Azure Landing Zone Design
* AZ-07 Azure Monitoring & Operations
