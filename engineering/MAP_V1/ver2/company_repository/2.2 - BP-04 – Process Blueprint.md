# 1. Purpose

The Readiness Assessment Blueprint defines the standardized methodology for evaluating an organization's preparedness to undertake and successfully complete a migration programme.

It provides a structured framework for assessing readiness across business, technical, operational, governance, security, people, and commercial domains. The outcome is an evidence-based readiness score that informs executive decision-making and determines whether a programme can proceed to planning and execution.

---

# 2. Objectives

The Readiness Assessment Blueprint aims to:

* Establish an objective readiness baseline.
* Measure organizational preparedness across key domains.
* Identify gaps and remediation actions.
* Provide executive confidence through evidence-based scoring.
* Support governance decision gates.
* Prioritize improvement initiatives.
* Reduce migration risk.
* Enable consistent assessments across all engagements.

---

# 7. Readiness Maturity Model

Each domain is evaluated using a five-level maturity model.

| Level | Rating     | Description                         |
| ----- | ---------- | ----------------------------------- |
| 1     | Initial    | Ad hoc, undocumented processes      |
| 2     | Developing | Basic controls established          |
| 3     | Defined    | Documented and repeatable processes |
| 4     | Managed    | Measured and actively governed      |
| 5     | Optimized  | Continuously improved and automated |

# 8. Readiness Activities

## Phase 1 – Preparation

Activities:

* Review assessment outputs
* Review discovery findings
* Confirm assessment scope
* Identify domain owners
* Establish evidence repository

**Deliverable:** Readiness Assessment Plan

---

## Phase 2 – Domain Evaluation

Each domain owner:

* Reviews evidence
* Conducts interviews
* Confirms current maturity
* Identifies gaps
* Records findings

**Deliverable:** Domain Assessment Reports

---

## Phase 3 – Gap Analysis

Assess:

* Missing capabilities
* Process weaknesses
* Technology limitations
* Governance deficiencies
* Skill shortages
* Compliance gaps

**Deliverable:** Gap Register

---

## Phase 4 – Scoring

Calculate:

* Domain scores
* Overall readiness score
* Risk-adjusted readiness
* Executive readiness status

**Deliverable:** Readiness Scorecard

---

## Phase 5 – Validation

Conduct stakeholder workshops to:

* Validate findings
* Review recommendations
* Agree remediation priorities
* Obtain executive endorsement

**Deliverable:** Approved Readiness Report

---

# 9. Readiness Scoring Framework

|   Score | Readiness Status   | Decision                     |
| ------: | ------------------ | ---------------------------- |
|   0–20% | Not Ready          | Programme should not proceed |
|  21–40% | Low Readiness      | Major remediation required   |
|  41–60% | Moderate Readiness | Proceed with conditions      |
|  61–80% | Ready              | Minor remediation required   |
| 81–100% | Fully Ready        | Approved to proceed          |

---

# 17. Best Practices

* Use cross-functional assessment teams.
* Validate all findings with evidence.
* Weight business impact above technical preference.
* Reassess readiness after major programme changes.
* Align remediation actions with programme priorities.
* Present results in executive-friendly dashboards.
* Maintain traceability from findings to recommendations.
