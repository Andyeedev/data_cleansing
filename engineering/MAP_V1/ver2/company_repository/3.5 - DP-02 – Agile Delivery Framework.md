# DP-02 – Agile Delivery Framework

## Migration Assurance Platform (MAP)

Version 1.0
Status: Complete

---

# Purpose

This document defines the Agile Delivery Framework for the Migration Assurance Platform (MAP).

The framework establishes the Agile operating model, team structures, sprint execution approach, governance controls, ceremonies, estimation model, and delivery management practices that will be used to build and deliver MAP Release 1.

This framework translates the Delivery Strategy (DP-01) into a practical execution model.
