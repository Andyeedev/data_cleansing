# Core Aggregate

## Migration Programme

The Migration Programme is the top-level business entity.

All platform activities occur within the context of a migration programme.

---

# Migration Programme

## Description

Represents a transformation initiative.

Examples:

* Core Banking Migration
* Policy Administration Migration
* Data Centre Exit
* Cloud Migration Programme

---

## Attributes

| Attribute    | Description          |
| ------------ | -------------------- |
| Programme ID | Unique identifier    |
| Name         | Programme name       |
| Description  | Business description |
| Status       | Lifecycle status     |
| Start Date   | Planned start        |
| End Date     | Planned end          |
| Owner        | Programme owner      |

# Lifecycle Overview

## Discovery Lifecycle

Registered → Assessed → Approved → Active → Retired

---

## Mapping Lifecycle

Draft → Review → Approved → Active → Superseded

---

## Validation Lifecycle

Defined → Executed → Reviewed → Closed

---

## Defect Lifecycle

Open → Assigned → Resolved → Closed

---

## Governance Lifecycle

Submitted → Reviewed → Approved/Rejected

---

# Domain Integrity Rules

## Rule 1

Every Mapping must belong to a Migration Programme.

---

## Rule 2

Every Validation Rule must reference a Mapping.

---

## Rule 3

Every Validation Result must originate from a Validation Run.

---

## Rule 4

Every Approval must belong to a Workflow.

---

## Rule 5

Every Audit Record must reference a valid entity.

---

## Rule 6

Every User must have at least one Role.
