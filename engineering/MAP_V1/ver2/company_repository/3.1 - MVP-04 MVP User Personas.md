# MVP-04 – MVP User Personas

## Migration Assurance Platform (MAP)

Version 1.0
Status: Complete

---

# Purpose

This document defines the primary user personas for the Migration Assurance Platform (MAP) MVP.

The personas represent the users who will interact with MAP during migration and transformation programmes.

The personas provide the foundation for:

* UX Design
* Information Architecture
* Navigation Design
* Role-Based Security
* User Stories
* Product Backlog Creation
* Pilot Customer Validation
