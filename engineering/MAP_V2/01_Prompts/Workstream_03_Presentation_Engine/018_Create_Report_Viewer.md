Purpose

Create the enterprise Report Viewer for MAP Nexus™.

The Report Viewer provides the reusable viewing experience used to display every report generated by MAP.

This prompt creates only the presentation framework.

No report generation.

No backend integration.

No APIs.

No export functionality.

Objective

Create a reusable Report Viewer capable of rendering all MAP reports within a consistent enterprise viewing experience.

The Report Viewer shall support every reporting engine developed later.
