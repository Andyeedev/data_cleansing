# 048_Create_Containerisation.md

## Workstream 09: Deployment

### Task: Create Containerisation

**Purpose:** Containerise application components for consistent deployment across environments.

**Scope:**
- Dockerfile for backend API
- Dockerfile for frontend application
- Docker Compose for local development
- Container health checks
- Environment variable configuration
- Volume mounts for development
- Multi-stage builds for optimisation

**Dependencies:**
- Application builds successfully
- Dependencies identified

**Acceptance Criteria:**
- Backend container builds and runs
- Frontend container builds and runs
- Docker Compose starts full stack locally
- Health checks respond correctly
- Environment variables configurable

**Evidence:**
- Dockerfiles
- docker-compose.yml
- Build and run logs
