# Purpose

The Engineering folder contains the governance documentation used to control the design, implementation, operation and maintenance of the Migration Assurance Platform (MAP).

These documents provide the engineering standards that every implementation activity must follow.

The folder acts as the single source of truth for engineering governance throughout the lifecycle of the platform.

---

# Objectives

The objectives of this folder are to:

* Provide consistent engineering governance.
* Ensure OpenCode follows approved implementation standards.
* Maintain alignment with the approved MAP architecture.
* Standardise development practices.
* Improve consistency across all implementation activities.
* Reduce prompt complexity.
* Support long-term maintainability.

---
